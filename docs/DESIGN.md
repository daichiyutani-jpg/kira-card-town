# キラカード・タウン 設計書（正本）

スマートフォン縦画面向けの、完全オリジナルのカード収集・街探索・カードバトルRPG。
URLで開くWebゲーム（PWA）。ひとり用はすべてオフラインで動く。課金なし（ゲーム内通貨「コイン」のみ）。

## 1. 技術構成

| 層 | 中身 | 場所 |
|---|---|---|
| データ | カード・NPC/CPU・マップ・大会・ショップ・経済・ガチャ・ストーリー・お手伝い（すべてJSON） | `src/data/*.json` |
| バトルエンジン | ルール・効果・サイコロ・勝敗。画面に依存しない純ロジック。乱数は種つき（同じ種なら同じ結果） | `src/engine/` |
| CPU思考 | 正規の行動だけを選ぶ（相手の手札や山札は見ない） | `src/engine/ai.ts` |
| ゲーム進行 | セーブ・所持品・経済・大会・お祭り判定・ストーリー | `src/game/` |
| 画面 | DOM＋Canvas（街のマップ）。フレームワークなし | `src/ui/` |
| 絵 | カードイラストはSVGをプログラムで生成（カードごとに体型・部品・色・ポーズ・背景が違う）。画像ファイルに差し替え可（`art.img`） | `src/art/` |
| 音 | Web Audio でBGM・効果音を生成。音声ファイルに差し替え可（`src/audio/sound.ts` の `FILES`） | `src/audio/` |
| 通信 | URL招待＋WebRTCの直接通信（サーバー不要）。両端末が同じ行動列を同じ種で再生して照合 | `src/net/` |
| オフライン | Service Worker で全ファイルを事前キャッシュ | `sw/sw-template.js` |

TypeScript 7 / Vite 8 / Vitest 5。ブラウザの総合テストは playwright-core＋インストール済みEdge。

## 2. バトルルール（v1）

- ライフ（LP）20。デッキ20枚ちょうど。同じカードは3枚まで、ウルトラレアは1枚まで。
- 最初に手札4枚。先攻の1ターン目はドローなし・攻撃なし。
- 1ターンにできること：モンスターの召喚1回／魔法カード1枚／アイテムカード1枚／場の各モンスターが1回ずつ攻撃または「まもる」。
- 場のモンスターは3体まで。
- **生け贄召喚**：Lv1〜3はそのまま。Lv4〜5は1体、Lv6〜7は2体を生け贄にする。カードによって独自の条件あり（特定属性の生け贄、特定カードの生け贄、LPが少ないと生け贄なし など）。
- **攻撃**：相手の場にモンスターがいれば、どれかを狙う。いなければ相手に直接攻撃。
- **サイコロ**：攻撃側と守備側が1個ずつ振る。出目の補正は `1:-1 / 2:0 / 3:0 / 4:+1 / 5:+1 / 6:+2`（出目だけで勝負が決まらない幅）。
- **属性**：炎→風→地→水→炎（矢印の先に強い）。光と闇はおたがいに強い（攻撃した側に付く）。有利な側に+2。
- **計算**：攻撃力＝攻撃＋強化＋出目補正＋属性。守備力＝守備＋強化＋出目補正＋属性（＋まもる中は+2）。
  - 攻撃力が上 → 守備モンスターを倒し、差の分だけ相手にダメージ。
  - 同じ → 何も起きない。
  - 守備力が上 → はね返され、差の分だけ攻撃した側にダメージ（倒されはしない）。
  - 直接攻撃 → 攻撃＋強化＋出目補正（最低1）のダメージ。
- **勝敗**：相手のLPを0にする／相手がドローできない（山札切れ）／30ターン（各15）経過でLPが多い方の勝ち（同じなら引き分け）。
- **キーワード**：そら（相手の場に「そら」がいなければ直接攻撃できる）・かべ（相手はまずこれを狙う）・れんげき（1ターン2回攻撃）・ラッキー（サイコロを2回振り高い方）・かくれみ（魔法・アイテムの対象にならない）・しぶとい（1度だけ破壊されない）。
- **効果**：`fx` 配列。発動タイミング（召喚・攻撃・破壊・ターン開始・使用・装備・常時）と処理（ダメージ・回復・強化・破壊・ドロー・手札に戻す・復活・サーチ・しぶとい付与・行動不能・手札破壊 など）と対象と条件の組み合わせ。処理の追加は `src/engine/effects.ts` に1つ足すだけ。

## 3. 世界・ステージ

「キラ星」のかけらから生まれたカードの住人が暮らす国。主人公は小学5年生。
- ステージ1 はじまりの街「ひだまり町」：自宅（自分の部屋の机でだけデッキ編集）・カードショップ・大会会場・配達アルバイト・チュートリアル
- ステージ2 商業地区「にぎわい通り」：大型ショップ・商品仕分けアルバイト・大会（攻撃・コンボ型）
- ステージ3 自然の街「みどりの森町」：森の探索・自然探索アルバイト・大会（属性型）
- ステージ4 「キラ星学園」：学生8人（攻撃・防御・属性・効果などの戦術）。何度でも対戦
- ステージ5 「星まつり」：月・水・金・日の18:00〜20:00（端末の現地時刻）だけ出現。カードくじ・ガチャ・期間限定カード

ストーリー：0 目覚め→ショップで初期デッキ→チュートリアル／1 ひだまりカップ優勝→にぎわい通りへ／2 にぎわいカップ優勝→みどりの森町へ／3 みどりカップ優勝→学園の屋上でライバル戦→4 チャンピオン戦（ひだまり町の大会会場）→エンディング。クリア後も大会・学園・お祭り・図鑑集めが続く。

## 5. オンライン対戦（サーバーなし方式）

1. 部屋を作る → 招待URL（WebRTCの接続情報を圧縮してURLの # 以降に入れる）→ LINEで送る
2. 友達がURLを開く → デッキを選ぶ → 「返事コード」が出る → LINEで送り返す
3. 作った側が返事コードを貼る → 直接つながる（Googleの公開STUNサーバーで経路を探す。通信内容はサーバーを通らない）
4. サイコロの種は両者の乱数を「先に指紋（ハッシュ）を送ってから中身を見せる」方式で混ぜる＝片方だけで出目を決められない
5. 行動だけを送り合い、両端末が同じエンジンで再生して状態の指紋を照合（食い違えば無効試合）
6. 切断したら「通信が切れた」と表示し、勝敗は記録しない

制限：携帯回線どうしなどでつながらない組み合わせがある（中継サーバー＝TURNがないため）。確実にするには有料/無料枠のTURNや Cloudflare Workers などの中継が必要（`docs/ONLINE.md`）。端末の時計は対戦に使わない。

## 6. セーブ

localStorage（キー `kira-card-town-save-v1`）に本体と予備の2つ。版番号つきで、読み込み時に `migrate()` で補完。
壊れていたら予備から復元、両方だめなら壊れたデータを退避して新規。タイトルから引き継ぎコードの書き出し・読み込み。
