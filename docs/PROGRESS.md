## テスト中に見つけて直した不具合
- 初めて開いた時、オフライン用の準備が終わるとページが読みこみ直され、遊び始めた画面がタイトルへもどっていた → 読みこみ直しは「更新する」を押した時だけにした（2026-11-08・公開URLで確認）
- チュートリアルのガイドが相手の場を隠し、攻撃する相手をタップできなかった → ガイドを画面の上に「場所をとって」置くようにした
- ゲームを開いたままの画面で招待URLを開くと反応しなかった → URLの変化でも招待を受け取るようにした
- 攻撃の計算表示で、攻撃したモンスターの名前を取り違えることがあった → 修正
- 音が出せない端末で音の準備に失敗すると止まるおそれ → 失敗しても遊べるようにした
- 光属性（黄色い背景）のカードで星・番号・攻撃守備の数字・名前が読みにくかった → 文字を白＋影、星を濃いオレンジにし、キラ加工が文字にかぶらないようにした（2026-11-07）
