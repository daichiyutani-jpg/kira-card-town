# キラカード・タウン

遊ぶ：https://daichiyutani-jpg.github.io/kira-card-town/ （スマホのブラウザで開き、ホーム画面に追加するとアプリのように使えます）

スマホで遊ぶオリジナルのカードバトルRPG（PWA・縦画面・タッチ操作）。街を歩いてカードを集め、大会で優勝し、ライバルとチャンピオンに挑む。友達との対戦以外は、オフラインでも遊べる。

- 本物のお金を払う場所はない（ゲームの中のコインだけ）。
- セーブはこの端末のブラウザの中だけ（外へ送らない）。引き継ぎは「引き継ぎコード」で行う。
- 友達との対戦は2台を直接つなぐ方式（サーバーなし・無料）。くわしくは [docs/ONLINE.md](docs/ONLINE.md)。

## 開発
```
npm.cmd install
npm.cmd run dev          # 開発サーバー
npm.cmd test             # 単体テスト
npm.cmd run build        # 型チェック＋本番ビルド（dist/）
npm.cmd run test:e2e     # ブラウザ総合テスト（Edge）
npm.cmd run icons        # アイコン画像を作り直す
```
PowerShell では `npm` ではなく `npm.cmd` を使う。

## 構成
- `src/engine/` バトルのルール（画面と分離・決まった乱数で再現できる）と CPU AI
- `src/data/` カード200枚・対戦相手・マップ・お店・ストーリー・経済（数値はここで調整）
- `src/game/` セーブ・カードの入手・大会・星まつりの時間
- `src/ui/` 画面（街・バトル・ショップ・机・図鑑・大会・バイト・お手伝い・まつり・設定・オンライン）
- `src/net/` オンライン対戦（WebRTC・コミット公開・メッセージ検査）
- `src/art/` カード絵（SVGをプログラムで描くオリジナル）
- `docs/DESIGN.md` 設計・ルール、`docs/PROGRESS.md` 進捗と未確認の項目

## テスト用の入口
- URLに `?now=2026-11-06T18:30:00` を付けると、その時刻として星まつりの開催を判定する（テスト用）。
- URLに `?e2e` を付けると、自動テスト用の `window.__kira` が使える（ふだんは無効）。
